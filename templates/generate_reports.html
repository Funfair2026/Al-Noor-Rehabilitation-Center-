Report Contents

The Excel file contains the following sheets with comprehensive user data:

  • Visitors: All visitor QR codes with ticket ID, name, amounts, balance, issue date, and issued by admin
  • Revenue Transactions: All Issue and Top-up transactions with visitor name, amount, type, admin, and date
  • Counter Transactions: All payment transactions with counter name, amount, staff, customer, and time
  • Admin Users: All admin accounts with username, role, last login, created date, status, and created by

The report is downloaded as a single Excel (.xlsx) file with multiple sheets.
